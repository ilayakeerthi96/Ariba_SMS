# Lead Capturing - Spring Boot (Full Version)\n\nThis is a minimal Spring Boot project with JWT-based authentication, role-based access control and sample data pre-loaded into an in-memory H2 database.\n\n## Run\n1. Install Java 17 and Maven.\n2. `mvn spring-boot:run`\n3. H2 Console: http://localhost:8080/h2-console (JDBC URL: jdbc:h2:mem:lead_db)\n4. Login:\n   - admin@example.com / adminpass\n   - rashid@example.com / password\n   - swaty@example.com / password\n5. Endpoints:\n   - POST /api/auth/login  => { email, password } returns { token }\n   - GET /api/dashboard/summary (auth required)\n   - CRUD under /api/leads, /api/opportunities, /api/targets (role-restricted)\n
